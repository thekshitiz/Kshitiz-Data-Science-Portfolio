## 📖 How to Use

1. Browse the project list above.
2. Open a project folder or README to explore the analysis and code.
3. Clone the repository and run the projects locally using the instructions in each folder.

```bash
git clone https://github.com/thekshitiz/Kshitiz-Data-Science-Portfolio.git
cd Kshitiz-Data-Science-Portfolio
```
