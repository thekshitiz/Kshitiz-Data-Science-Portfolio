## 📖 How to Use

1. Browse through the list of projects above.
2. Click on the project name to view its README and setup instructions.
3. Clone the repository and follow individual project setups to run locally.

```bash
git clone https://github.com/thekshitiz/Kshitiz-Data-Science-Portfolio.git
cd project-folder-name
```
