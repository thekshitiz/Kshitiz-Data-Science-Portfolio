# 🇬🇧 British Airways Data Science: Predicting Customer Buying Behaviour

This repository contains my completed tasks from the **British Airways Data Science Virtual Experience Program** hosted on [Forage](https://www.theforage.com/), where I gained hands-on experience in using data science to drive business decisions at a global airline.

---

## ✈️ Project Overview

British Airways is a world-renowned airline, and like any large-scale operation, it relies heavily on data to optimize its services and enhance customer experience. This job simulation mimics real-world challenges faced by BA’s Data Science team.

The simulation is split into **two tasks**:

1. **Web Scraping for Customer Insights**  
2. **Predicting Customer Buying Behaviour**

Each task provided a practical opportunity to work with data, develop insights, and communicate results clearly.

---

## 🧩 Tasks Breakdown

### ✅ Task 1: Web Scraping for Customer Insights

**Objective:**  
Scrape and analyse third-party customer reviews to identify key trends in sentiment, common issues, and opportunities for service improvement.

**What I did:**

- Used Python libraries like `requests`, `BeautifulSoup`, and `pandas` for data collection and parsing.
- Performed **text preprocessing** and **sentiment analysis** on customer feedback.
- Generated insights into customer satisfaction and dissatisfaction themes.
- Delivered findings via a **PowerPoint presentation** summarizing customer sentiment trends.

---

### ✅ Task 2: Predicting Customer Buying Behaviour

**Objective:**  
Train a machine learning model to predict whether a customer would complete a booking based on behavioural data.

**What I did:**

- Explored the dataset provided in a Jupyter Notebook.
- Cleaned, engineered features, and prepared the dataset for modeling.
- Trained a **Random Forest Classifier** and evaluated it using metrics such as accuracy, F1 score, and confusion matrix.
- Identified key variables that influence customer booking decisions.
- Visualized feature importances and summarized the results in a PowerPoint slide.
